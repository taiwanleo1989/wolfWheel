① 貼到 ElevenLabs 的文字

隱狼請睜眼。……。隱狼請閉眼。……。

同一段文字也在檔案：wolfWheel\voice-src\第八批-貼到ElevenLabs.txt

中間的「……」是讓兩句之間有停頓、好切開，照原樣貼上就好，不要刪。

② 在 ElevenLabs 網頁上產生（跟前七批一樣）

  1. 打開 ElevenLabs 的 Text to Speech 網頁。
  2. 聲音選 Liu Junnan，模型選 v4。
  3. 設定照前七批：速度 1.00、穩定度 33%、相似度 75%（這是從第一批檔名 …_pvc_sp100_s33_sb75_v4.mp3 讀出來的；如果網頁上的名稱不一樣，照著對應就好）。
  4. 貼上 ① 的文字，按產生，先聽一次：兩句都有唸、「隱」沒有唸錯就下載 mp3。

③ 下載的檔案放這裡

把下載的 mp3 改名、放到：

C:\Users\Leo\claudeCode workspase\wolfWheel\voice-src\batch8.mp3

檔名一定要是 batch8.mp3（前七批也是 batch2～batch7 這樣排）。放好之後跟 Claude 說「第八批錄好了」，Claude 會：

  1. 把這批登記進 voice-src/batches.json。
  2. 跑 npm run voice:split：用 ElevenLabs 的強制對齊把兩句切成 public/voice/hiddenOpen.mp3、hiddenClose.mp3。
  3. 把角色說明頁、主持台詞頁上「還沒錄音」那行拿掉（自動測試會核對）。
  4. 重新整理這一頁，在下面 ④ 試聽；你聽過 OK 再一起部署。
