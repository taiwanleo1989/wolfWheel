# 法官工具規格（v0.3，2026-10-10；10-08 草稿後陸續依 Leo 拍板更新）

> 一句話：**一支主機手機發出聲音，其他手機各自接收訊息、私下操作**。大家都在現場、都能下場玩；身分與夜裡的動作只在自己手機上看、在自己手機上點，沒有人需要伸手去碰別人的手機。
>
> v0.1 → v0.2：Leo 拍板「直接做多機連線版」（2026-10-08）。

---

## 1. 誰拿什麼

| 裝置 | 誰 | 畫面 | 聲音 |
|---|---|---|---|
| **主機** | 開房的人（他自己也可以是玩家） | 公開資訊：房號、誰加入了、現在第幾晚、天亮公告 | **只有主機出聲**：唸台詞、背景音樂 |
| **玩家手機** | 每個玩家 | 自己的身分、輪到自己時的操作按鈕 | **靜音**（避免洩漏誰在操作） |

**最重要的原則：身分只存在伺服器上。** 主機手機也拿不到別人的身分，所以開房的人照樣能玩，不會作弊、也不會被懷疑。

---

## 2. 一局怎麼走

```
① 開房 → ② 加入＋選座位 → ③ 設定 → ④ 發牌 → ⑤ 黑夜 → ⑥ 天亮
                                                  ↑          ↓
                                                  └─ ⑧ 入夜 ← ⑦ 白天（放逐）
                                       每次天亮／放逐後檢查勝負 → ⑨ 結算
```

| 階段 | 主機 | 玩家手機 |
|---|---|---|
| ① 開房 | 按「開新房間」→ 顯示 **QR code＋4 位房號** | — |
| ② 加入 | 即時顯示座位表（幾號已有人） | 掃 QR 或輸入房號 → 選自己的座位號碼 |
| ③ 設定 | 選板子、規則（女巫自救、勝負、假等秒數） | 等待 |
| ④ 發牌 | 伺服器亂數分配；主機唸「請查看自己的身分」 | **自己手機上**看身分（角色卡），看完按「我看好了」 |
| ⑤ 黑夜 | 唸「天黑請閉眼……狼人請睜眼」 | 輪到的角色：手機出現操作按鈕；**其他人的畫面一律是同一個「閉眼中」畫面** |
| ⑥ 天亮 | 唸「平安夜」或「X 號、Y 號死亡」；獵人／狼王可開槍時**主機不提示**（點名＝公開身分） | 死者手機顯示「你已出局」；能開槍的人手機出現開槍按鈕 |
| ⑦ 白天 | 發言投票照你們平常口頭進行；主機上點「被放逐的是幾號」 | 被放逐者手機顯示出局 |
| ⑨ 結算 | 唸哪邊贏，翻開所有人身分 | 同步顯示結算 |

開局的發言順序可以接上現有的轉盤（主機上按「決定發言順序」）。

## 3. 支援的角色

| 陣營 | 角色 | 夜裡要做的事（在自己手機上） |
|---|---|---|
| 狼人 | 狼人 | 選一個人殺。**多隻狼要一致**：每隻狼手機上看得到同伴目前選誰，全部選同一人才算數 |
| 狼人 | 狼王 | 同狼人；被殺或被放逐可開槍帶走一人（被毒不能開槍） |
| 神 | 預言家 | 查驗一人 → 自己手機顯示「好人／狼人」 |
| 神 | 女巫 | 看到今晚死者 → 選「救」「毒某人」或「不用」；解藥、毒藥各一瓶 |
| 神 | 獵人 | 夜裡不動作；被殺或被放逐可開槍（被毒不能開槍） |
| 神 | 守衛 | 守護一人（不能連續兩晚守同一人） |
| 神 | 騎士 | 夜裡不動作；白天在自己手機上發起決鬥：對方是狼 → 對方死、今天不放逐、主機唸「天黑請閉眼」，主機按「進入黑夜」才開始夜晚；不是 → 騎士死、白天繼續投票（Leo 2026-10-10） |
| 神 | 白癡 | 夜裡不動作；被放逐時在自己手機選：翻牌免死（失去投票權）或不翻直接出局；30 秒沒選＝不翻、出局，主機不能代按（Leo 2026-10-10：只有白癡會出現這個等待，接受它會讓人猜到身分） |
| 民 | 平民 | 不動作 |

**預設板子**：預女獵白、狼王守衛、狼王騎士（12 人），也可以自訂各角色人數。

## 4. 防偷看、防偷聽

1. **所有玩家手機的「閉眼中」畫面完全一樣**，輪到你時才變出按鈕；玩家手機全程靜音、不震動。
2. **死掉的角色照樣唸、照樣等**；假等的秒數隨機（預設 8～15 秒，設定可調）。
3. **活著的角色**：點完按「完成」就走，再補 2～5 秒隨機等待才唸「請閉眼」。
4. **背景音樂只在主機播**，蓋掉環境雜音。

## 5. 天亮結算規則

- 狼刀的人：女巫救 → 活；守衛守 → 活；**同守同救 → 死**。
- 女巫毒的人 → 死，且不能開槍。
- 同晚死 0～2 人，宣布時**不說死因**。
- 女巫自救、勝負規則由設定頁決定（見第 9 節）。

## 6. 架構

```
 主機手機 ──┐                          ┌── 玩家手機 1
 （出聲）    ├── WebSocket ── 房間（伺服器）──┼── 玩家手機 2
            │                 · 存身分與整局狀態  └── …
            │                 · 推進夜晚流程、算天亮
            │                 · 每支手機只送它該知道的
```

- **伺服器**：Cloudflare Worker ＋ Durable Objects，**一個房間＝一個 Durable Object**，整局狀態存在裡面。規則（天亮結算、勝負判定）由伺服器算，手機只負責顯示和送出點選。
- **網頁**：轉盤與法官工具放同一個網站，跟伺服器一起部署在 Cloudflare（Worker 的靜態資產），一個指令更新、版本一定一致。原始碼仍在 wolfWheel repo。
- **規則程式**：寫成獨立的模組並附測試——規則錯了比畫面醜嚴重。

## 7. 現場一定會遇到的狀況（都要處理）

| 狀況 | 處理 |
|---|---|
| 手機螢幕自動關掉、連線斷了 | 用 Wake Lock 讓螢幕保持亮著；斷線回來自動重連，回到正確畫面（座位記在手機裡） |
| 有人不小心關掉網頁 | 重新掃 QR → 自動認出是原本的座位，接回整局 |
| 主機斷線 | 換一支手機用房號接手當主機，遊戲狀態都在伺服器，不會遺失 |
| iPhone 不讓網頁自己出聲 | 主機開局時按一次「開始」解鎖語音（瀏覽器規定，只要一次） |
| 房間放著沒人用 | 最後一個人離開 2 小時後自動清掉 |

## 8. 第一版**不做**的事

- 進階角色：白狼王、狼美人、隱狼、混血兒、丘比特等
- 帳號、戰績統計

## 9a. 照 Leo 手稿調整（2026-10-08，取代下方 9b 衝突的部分）

**黑夜順序**：天黑請閉眼 → 守衛 → 狼人 → 女巫（解藥、毒藥兩段）→ 預言家 → 獵人 →（第一晚）上警 → 天亮請睜眼。台詞放在 `src/engine.js` 的 `scriptFor()`，改台詞只改那裡。

| 段落 | 主機唸（不唸號碼） | 當事人手機 |
|---|---|---|
| 守衛 | 守衛請睜眼。請選擇今晚要守護的玩家。…守衛請閉眼。 | 選號碼 →「今晚要守護的玩家是 N 號，是否正確？」 |
| 狼人 | 狼人請睜眼。狼王請確認身分（板子有狼王才唸）。今晚要擊殺的目標是？…狼人請閉眼。 | 看得到狼王是誰；全體一致 →「今晚要擊殺的玩家是 N 號，是否正確？」任一隻按正確 |
| 女巫 | 女巫請睜眼。今晚死亡的玩家是——請問你要使用解藥嗎？／請問你要使用毒藥嗎？如果要，請選擇你要毒殺的號碼。…女巫請閉眼。 | 顯示死亡號碼（解藥用掉就不顯示）、👍 救／👎 不救；毒藥選號碼 →「是否正確」 |
| 預言家 | 預言家請睜眼。請問你今晚要查驗的玩家是？…預言家請閉眼。 | 選號碼 →「是否正確」→ 👍 好人／👎 狼人 |
| 獵人 | 獵人請睜眼。獵人，你今晚的帶槍手勢是——…獵人請閉眼。 | 👍 可以開槍／👎 被毒不能開槍 |
| 上警（第一晚） | 要上警的玩家請起立。→ 天亮請睜眼。 | —（主機按「大家都起立好了」或 12 秒自動） |

**Leo 拍板**：女巫預設不能自救（設定仍可改）；一晚只能一瓶；第一天**警長選完才公布死訊**（主機按「公布昨晚死訊」，在那之前座位表不顯示誰死、不能放逐／天黑）；警長只唸台詞、口頭進行，工具不記錄。

## 9b. M3／M4 實作時採用的預設規則（2026-10-08，Leo 說「直接全部做完」，玩過覺得不對再改）

| 項目 | 做法 |
|---|---|
| 狼人投票 | 在線上、還活著的狼全部選同一人才確定；可「空刀」；每隻狼看得到隊友的票 |
| 女巫 | 一晚只能用一瓶；解藥用掉後看不到誰被殺；不能毒自己；自救依設定 |
| 守衛 | 不能連續兩晚守同一人；可空守；同守同救＝死 |
| 預言家 | 一晚查一人，結果只在自己手機；查驗紀錄可隨時看 |
| 開槍 | 獵人／狼王被刀、被放逐、被槍帶走、被騎士決鬥 → 自己手機私下跳出開槍；**主機不點名**（點名＝公開身分）；開了才宣布；被毒不能開 |
| 騎士 | 白天在自己手機發起決鬥，只能一次；撞到狼直接天黑（不放逐），撞到好人繼續投票 |
| 白癡 | 第一次被放逐由本人選翻不翻：翻＝免死、失去投票權；不翻＝出局。翻過牌再被放逐直接出局 |
| 卡住 | 夜裡角色的步驟不限時。主機的「跳過（睜眼 30 秒後可按）」：每個角色一樣——睜眼就出現（灰的）、30 秒後才能按（伺服器也擋），文字不提角色；跳過＝當作沒動作。死掉的角色假等最多 15 秒，按鈕亮不起來，所以不比「拖多久」多洩漏（Leo 2026-10-10）。上警另有「大家都起立好了」 |
| 被動技能 | 獵人／狼王開槍、白癡翻牌**不限時**，一直等本人按（Leo 2026-10-10 實玩後拿掉 30 秒）。開槍後主機唸「7 號發動技能，帶走了 4 號。」。主機按天黑不會被擋，按了就作廢沒開的槍（主機不能知道誰能開槍） |
| 時間 | 天黑後 5 秒第一個角色睜眼；「X 請閉眼」後 4 秒換下一個；活著的角色點完再隨機停 2–5 秒 |

## 10. 做法與工期（約 7～8 天）

**進度（2026-10-08）**：M1～M4 完成並上線（Worker `wolfwheel`）；M5 現場實測待 Leo。自動測試 44 個；另用模擬手機跑過完整對局（本機 12 人、線上 9 人）。

| 里程碑 | 內容 | 預估 |
|---|---|---|
| M1 | 伺服器房間：開房、加入、選座位、斷線重連 | 1.5 天 |
| M2 | 設定＋發牌（各自手機看身分） | 1 天 |
| M3 | 黑夜流程：伺服器推進、主機語音、各手機私下點選、隨機假等 | 2 天 |
| M4 | 天亮結算、開槍、白天放逐、騎士決鬥、勝負（規則模組＋測試） | 1.5 天 |
| M5 | 多支 iPhone 現場實測一整局、修問題 | 1 天 |

每個里程碑做完都先給 Leo 看、確認後再往下。
