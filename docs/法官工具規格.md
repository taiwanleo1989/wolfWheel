# 法官工具規格（草稿 v0.2，2026-10-08）

> 一句話：**一支主機手機發出聲音，其他手機各自接收訊息、私下操作**。大家都在現場、都能下場玩；身分與夜裡的動作只在自己手機上看、在自己手機上點，沒有人需要伸手去碰別人的手機。
>
> v0.1 → v0.2：Leo 拍板「直接做多機連線版」（2026-10-08）。

---

## 1. 誰拿什麼

| 裝置 | 誰 | 畫面 | 聲音 |
|---|---|---|---|
| **主機** | 開房的人（他自己也可以是玩家） | 公開資訊：房號、誰加入了、現在第幾晚、天亮公告 | **只有主機出聲**：唸台詞、背景音樂 |
| **玩家手機** | 每個玩家 | 自己的身分、輪到自己時的操作按鈕 | **靜音**（避免洩漏誰在操作） |

**最重要的原則：身分只存在伺服器上。** 主機手機也拿不到別人的身分，所以開房的人照樣能玩，不會作弊、也不會被懷疑。

---

## 2. 一局怎麼走

```
① 開房 → ② 加入＋選座位 → ③ 設定 → ④ 發牌 → ⑤ 黑夜 → ⑥ 天亮
                                                  ↑          ↓
                                                  └─ ⑧ 入夜 ← ⑦ 白天（放逐）
                                       每次天亮／放逐後檢查勝負 → ⑨ 結算
```

| 階段 | 主機 | 玩家手機 |
|---|---|---|
| ① 開房 | 按「開新房間」→ 顯示 **QR code＋4 位房號** | — |
| ② 加入 | 即時顯示座位表（幾號已有人） | 掃 QR 或輸入房號 → 選自己的座位號碼 |
| ③ 設定 | 選板子、規則（女巫自救、勝負、假等秒數） | 等待 |
| ④ 發牌 | 伺服器亂數分配；主機唸「請查看自己的身分」 | **自己手機上**看身分（角色卡），看完按「我看好了」 |
| ⑤ 黑夜 | 唸「天黑請閉眼……狼人請睜眼」 | 輪到的角色：手機出現操作按鈕；**其他人的畫面一律是同一個「閉眼中」畫面** |
| ⑥ 天亮 | 唸「平安夜」或「X 號、Y 號死亡」；獵人／狼王可開槍時提示 | 死者手機顯示「你已出局」；能開槍的人手機出現開槍按鈕 |
| ⑦ 白天 | 發言投票照你們平常口頭進行；主機上點「被放逐的是幾號」 | 被放逐者手機顯示出局 |
| ⑨ 結算 | 唸哪邊贏，翻開所有人身分 | 同步顯示結算 |

開局的發言順序可以接上現有的轉盤（主機上按「決定發言順序」）。

## 3. 支援的角色

| 陣營 | 角色 | 夜裡要做的事（在自己手機上） |
|---|---|---|
| 狼人 | 狼人 | 選一個人殺。**多隻狼要一致**：每隻狼手機上看得到同伴目前選誰，全部選同一人才算數 |
| 狼人 | 狼王 | 同狼人；被殺或被放逐可開槍帶走一人（被毒不能開槍） |
| 神 | 預言家 | 查驗一人 → 自己手機顯示「好人／狼人」 |
| 神 | 女巫 | 看到今晚死者 → 選「救」「毒某人」或「不用」；解藥、毒藥各一瓶 |
| 神 | 獵人 | 夜裡不動作；被殺或被放逐可開槍（被毒不能開槍） |
| 神 | 守衛 | 守護一人（不能連續兩晚守同一人） |
| 神 | 騎士 | 夜裡不動作；白天在自己手機上發起決鬥：對方是狼 → 對方死；不是 → 騎士死 |
| 神 | 白癡 | 夜裡不動作；被放逐時翻牌免死、失去投票權 |
| 民 | 平民 | 不動作 |

**預設板子**：預女獵白、狼王守衛、狼王騎士（12 人），也可以自訂各角色人數。

## 4. 防偷看、防偷聽

1. **所有玩家手機的「閉眼中」畫面完全一樣**，輪到你時才變出按鈕；玩家手機全程靜音、不震動。
2. **死掉的角色照樣唸、照樣等**；假等的秒數隨機（預設 8～15 秒，設定可調）。
3. **活著的角色**：點完按「完成」就走，再補 2～5 秒隨機等待才唸「請閉眼」。
4. **背景音樂只在主機播**，蓋掉環境雜音。

---

## 5. 天亮結算規則

- 狼刀的人：女巫救 → 活；守衛守 → 活；**同守同救 → 死**。
- 女巫毒的人 → 死，且不能開槍。
- 同晚死 0～2 人，宣布時**不說死因**。
- 女巫自救、勝負規則由設定頁決定（見第 9 節）。

## 6. 架構

```
 主機手機 ──┐                          ┌── 玩家手機 1
 （出聲）    ├── WebSocket ── 房間（伺服器）──┼── 玩家手機 2
            │                 · 存身分與整局狀態  └── …
            │                 · 推進夜晚流程、算天亮
            │                 · 每支手機只送它該知道的
```

- **伺服器**：Cloudflare Worker ＋ Durable Objects，**一個房間＝一個 Durable Object**，整局狀態存在裡面。規則（天亮結算、勝負判定）由伺服器算，手機只負責顯示和送出點選。
- **網頁**：轉盤與法官工具放同一個網站，跟伺服器一起部署在 Cloudflare（Worker 的靜態資產），一個指令更新、版本一定一致。原始碼仍在 wolfWheel repo。
- **規則程式**：寫成獨立的模組並附測試——規則錯了比畫面醜嚴重。

## 7. 現場一定會遇到的狀況（都要處理）

| 狀況 | 處理 |
|---|---|
| 手機螢幕自動關掉、連線斷了 | 用 Wake Lock 讓螢幕保持亮著；斷線回來自動重連，回到正確畫面（座位記在手機裡） |
| 有人不小心關掉網頁 | 重新掃 QR → 自動認出是原本的座位，接回整局 |
| 主機斷線 | 換一支手機用房號接手當主機，遊戲狀態都在伺服器，不會遺失 |
| iPhone 不讓網頁自己出聲 | 主機開局時按一次「開始」解鎖語音（瀏覽器規定，只要一次） |
| 房間放著沒人用 | 最後一個人離開 2 小時後自動清掉 |

## 8. 第一版**不做**的事

- 不在現場的遠端玩家（語音只有主機有）
- 警長競選、投票計票、發言計時（白天照你們平常口頭進行）
- 進階角色：白狼王、狼美人、隱狼、混血兒、丘比特等
- 帳號、戰績統計

## 10. 做法與工期（約 7～8 天）

| 里程碑 | 內容 | 預估 |
|---|---|---|
| M1 | 伺服器房間：開房、加入、選座位、斷線重連 | 1.5 天 |
| M2 | 設定＋發牌（各自手機看身分） | 1 天 |
| M3 | 黑夜流程：伺服器推進、主機語音、各手機私下點選、隨機假等 | 2 天 |
| M4 | 天亮結算、開槍、白天放逐、騎士決鬥、勝負（規則模組＋測試） | 1.5 天 |
| M5 | 多支 iPhone 現場實測一整局、修問題 | 1 天 |

每個里程碑做完都先給 Leo 看、確認後再往下。

## 11. 待拍板：網站放哪裡

| 選項 | 說明 |
|---|---|
| **A. 全部搬到 Cloudflare**（推薦） | 網頁和伺服器一起部署，一個指令更新；你的金流、小海也在 Cloudflare，帳號現成。網址會變成 `xxx.workers.dev`（GitHub Pages 舊網址可以放一個自動轉址） |
| B. 網頁留 GitHub Pages，伺服器放 Cloudflare | 網址不變，但要管兩個地方，每次更新要部署兩次 |
