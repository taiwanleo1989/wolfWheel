角色說明

每個角色的技能、特殊限制，和遊戲實際怎麼判

每一條規則前面的小編號（例如 wolf-3）對應一個自動測試：測試照這條規則實際跑一次遊戲，結果不一樣就會失敗。所以這頁寫的，就是法官工具實際的判法。有疑問時講編號最快。

共通規則

陣營與勝負

  • 三種陣營：狼人陣營（狼人、狼王、白狼王、狼美人、隱狼、石像鬼）、神職（預言家、女巫、獵人、守衛、守墓人、騎士、白癡）、平民。神職和平民都是好人。
  • 屠邊（預設）：板子上有的神職全部出局、或板子上有的平民全部出局 → 狼人陣營獲勝。狼人陣營全部出局 → 好人獲勝。
  • 屠城（設定可選）：所有好人（神職＋平民）都出局才算狼人陣營獲勝。
  • 兩邊同時達成（例如同一晚刀死最後一個神、毒死最後一隻狼）→ 狼人陣營獲勝。
  • 狼人陣營已經全部出局、但狼王出局後還能開槍：先等他開。這一槍讓狼人的條件也達成（屠邊：帶走最後一個神或最後一個民；屠城：帶走最後一個好人）＝兩邊同時達成＝狼人勝；沒達成、不開槍、或主機按天黑作廢這一槍＝好人勝。
  • 綁票提早結束：天亮睜眼那一刻（第一天是公布死訊時；有人要開槍、警長要移交警徽就等處理完），活著的狼人陣營票數 ≥ 好人的票數 → 狼人陣營直接獲勝。翻過牌的白癡沒有票；警長算 1.5 票。好人還能「追輪次」時不判，見下一條。
  • 不算綁票的情況：
    ・警徽在好人手上（包括翻過牌的白癡拿著警徽）：守衛活著、女巫還有任一瓶藥、或獵人活著（夜裡還能追一個輪次）。
    ・警徽在狼人手上：騎士活著、還沒決鬥（白天還能撞一隻出去）。
    ・沒有警長：騎士活著、還沒決鬥；不然要狼剛好等於好人票數，而且守衛活著＋女巫還有毒藥。
  • 一狼一神一民：白天投完票（含平票沒人出局）只剩一隻狼、一個神、一個民 → 狼人陣營直接獲勝。好人還能翻盤就不判：屠邊只看守衛活著、女巫還有解藥；屠城另外也算女巫的毒藥、獵人、活著還沒決鬥的騎士。有人要開槍時（例如放逐的是獵人），先等他開完再判。
  • 公開身分只在規則本來就公開的時候：能開槍的人出局時主機喊「N 號，請啟動角色技能」（等於公開他是獵人或狼王，也透露他不是被毒死或殉情的）、白癡被放逐時等他選擇、騎士決鬥的結果、自爆、狼美人被放逐、被槍帶走、被白狼王帶走而魅惑的人還活著時唸「M 號殉情出局」（等於公開她是狼美人）、遊戲結束翻開所有人。主機手機也可以是玩家：只看得到自己的身分，主機畫面上看不到別人的身分。

黑夜順序

天黑請閉眼→守衛→狼人→狼美人→女巫→預言家→石像鬼→守墓人→獵人→上警（第一晚）→天亮
  • 板子上沒有的角色不唸；狼人那步是整個狼人陣營的刀人步驟，板子上只有隱狼、石像鬼也會唸「狼人請睜眼」。白狼王、隱狼、狼王沒有自己的一步（跟狼人一起）；狼王的「帶槍手勢」已經取消。守墓人從第二晚才開始；上警只有第一晚、而且設定可以關掉。
  • 死掉的角色照樣唸、照樣等，隨機假等 8～20 秒（設定可調，最長 24 秒），所以聽不出誰死了。女巫有兩句，假等時間分給兩句、不會等兩次。
  • 活著的角色 25 秒沒操作，主機再唸一次同一句（狼人那步只重唸「狼人今晚要擊殺的目標是？」）。死掉的角色假等比這短，所以不會重唸——聽到重唸＝那個角色還活著。
  • 主機的「跳過」：每一句台詞唸出後 25 秒才能按（防手機沒電卡死），跳過＝這一句當作沒動作。女巫的解藥、毒藥是兩句，各自重新算 25 秒、各自跳過。上警可以直接按「大家都起立好了」，不然 6 秒後自動往下；不管哪一種，都會再隨機停 2～5 秒才唸天亮（所以自動天亮大約 8～11 秒）。
  • 天亮結算：狼刀的人被女巫救、或被守衛守 → 活；同守同救 → 死；被毒的人 → 死。宣布時只說「昨晚死亡的是…」，不說死因；第一晚有上警時，主機按「公布昨晚死訊」才公布（警長選完再說）。

白天：投票、放逐、警長

  • 誰有票：活著的人都有票（隱狼等狼人陣營也有）；翻過牌的白癡沒有票。警長算 1.5 票。警長是白癡、翻了牌：警徽還留在他身上，但他沒有票，這 1.5 票就不算。
  • 主機按「進行投票」請大家進行投票。每個人在自己手機點號碼或棄票，先問「是否正確」；不能投自己、投了不能改。投票中大家只看到「已投幾人」；全部投完（或主機按結束，沒投的算棄票），每支手機同時出現統計：誰得幾票、誰投的、誰棄票。
  • 只有一個最高票 → 直接放逐，主機唸N 號被放逐出局。出局的人能開槍（獵人、狼王）接著喊N 號，請啟動角色技能。被放逐的是還沒翻牌的白癡就不唸，等他自己選。
  • 平票：主機選「平票 PK」、「平票，沒人出局」平票，今天沒有人出局。或「重新投票」。PK 時平手的人不能投票，其他人只能投平手的人（例如 10 人、1 號 2 號 PK，只有 3～10 號投）；PK 又平手可以再 PK。主機用手動登記「平票／沒人出局」也唸這一句（登記當下留著的投票結果是全部棄票時除外，見 day-5）。
  • 全部棄票（PK 那一輪大家都棄票也算）：沒人得票，主機選「全部棄票，沒人出局」今天沒有人出局。或重新投票。唸哪一句只看主機登記「沒人出局」當下還留著的那一輪投票結果：是全部棄票 → 唸這一句；其他情況（平票、沒投票、結果被騎士決鬥清掉）→ 唸「平票，今天沒有人出局。」
  • 警長：主機在競選完登記誰當警長（第一天死訊還沒公布時，昨晚死的人也能當選）；沒人當選可以按「警徽流失」。主機在白天可以用「登記錯了，改警長」更正、或在警徽撕掉／流失後重新登記（給主機改錯用的；今天已經要天黑時也可以補登記）；投票中、等警長選警徽、等白癡選擇時沒有這個按鈕，夜裡也沒有。登記了警長之後就沒有「警徽流失」可按，只能改成另一個人。
  • 警長出局（任何死法）：由他自己的手機選「移交給某個活著的人」或「撕掉警徽」，主機不能代按。他選了主機不唸，只寫在全場紀錄。選之前不能投票、放逐、決鬥、自爆、天黑。自爆的、被騎士撞死的、被帶走的是警長：等他選完才唸「天黑請閉眼」。
  • 開槍、白癡翻牌、騎士決鬥都不限時。還有人沒開槍時不能投票、不能放逐；主機按「天黑」＝作廢沒開的槍。
  • 投票中有人自爆、或騎士決鬥撞到狼 → 這輪投票作廢，今天直接天黑、不再投票。騎士決鬥撞到好人（投票中，或投完還沒放逐）→ 這輪投票和結果都作廢，主機重新進行投票（平票的結果也清掉，不能接著 PK）。
  • 警長競選中（死訊還沒公布）按騎士決鬥或自爆：先公布昨晚死訊，再照公布後的情況判。下面幾種情況死訊照樣公布，但這次技能不算（沒有用掉）：自己昨晚已經死了（已經出局，之後也不能再按）；對象昨晚已經死了（換一個人可以再按）；昨晚死的人要開槍（等他開完可以再按）；昨晚死的是剛登記的警長（等他選完警徽可以再按）。

狼人陣營

狼人 狼人陣營

每晚和狼隊友一起選一個人殺掉（不能刀狼美人）。白天隱藏身分，混在好人裡；投票放逐之前可以自爆，今天直接天黑。

技能

  • 每晚和狼隊一起選一個人殺。在線上、活著的狼（含隱狼）全部選同一人才出現「是否正確」，任何一隻按正確就確定；掉線的狼不算。可以「空刀」。任何一隻按「重選」會清掉所有狼的選擇，大家重新點。隊友中途掉線時確認不會自己跳出來：任何一隻再點一次同一個號碼，就會出現「是否正確」。
  • 狼隊（狼人、狼王、白狼王、狼美人）晚上互相看得到彼此和彼此選誰；看不到隱狼的號碼（只看到「隱狼：選幾號」），也不知道石像鬼是誰。隊友名單會標出誰是狼王；刀人畫面上狼美人那格標「不能刀」，所以也知道誰是狼美人；白狼王不另外標。
  • 自爆：白天、投票放逐之前（警長競選中、投票中也可以）在「看我的身分」裡自爆，主機唸N 號狼人自爆，天黑請閉眼。（自爆的是警長：先唸「N 號狼人自爆。」，等他選完警徽才唸天黑，見 day-7）今天不放逐，主機按「進入黑夜」。警長競選中自爆＝先公布昨晚死訊再自爆（哪些情況自爆不算，見 day-10）。

限制

  • 不能刀狼美人（刀人畫面那格標「不能刀」）；其他活著的人都能刀，包含狼隊友自己。
  • 今天的放逐登記之後不能自爆：只有一個最高票時投完票就自動放逐；平票或全部棄票時要等主機按「沒人出局」才算（在那之前，包括 PK 中，還能自爆）；白癡被放逐不管翻不翻都算。有人要開槍或要選擇（白癡、警長移交）時、今天已經要天黑時，也不能。
  • 預言家查是狼人；守墓人看是狼人；騎士撞到＝狼人。

狼王 狼人陣營

狼人陣營，晚上和狼隊友一起殺人。被狼刀、被放逐、被槍帶走、被騎士撞死或被白狼王帶走時，可以開槍帶走一人；被女巫毒死、殉情、自爆不能開槍。

技能

  • 晚上和狼隊一起殺人；狼人睜眼時主機唸狼人請睜眼。狼王請確認身分。今晚要擊殺的目標是？（看板子上有沒有狼王，狼王出局後也照唸）。
  • 開槍：被狼刀（包括同守同救而死）、被放逐、被獵人的槍帶走、被騎士撞死、被白狼王帶走出局 → 自己手機出現開槍，可以帶走一個活著的人或不開；主機喊N 號，請啟動角色技能。開了唸N 號發動技能，帶走了 M 號。不開槍時主機不唸、紀錄也不寫。
  • 狼人陣營其他人都出局了、但狼王還能開槍 → 先等他開槍再判勝負（見 all-5）。騎士撞死狼王 → 先開槍，開完才唸天黑請閉眼。

限制

  • 被女巫毒死、殉情、自爆不能開槍。
  • 夜裡沒有「狼王帶槍手勢」這一步（已取消）。

白狼王 狼人陣營

狼人陣營，晚上和狼隊友一起殺人。白天投票放逐之前（警長競選中、投票中也可以）可以自爆，可以帶走一個人或不帶，今天直接天黑；不是自爆出局就不能帶人。

技能

  • 晚上和狼隊一起殺人。
  • 自爆帶人：白天、投票放逐之前（警長競選中、投票中也可以）自爆，可以帶走一個活著的人或不帶。主機唸N 號白狼王自爆，帶走了 M 號。天黑請閉眼。（不帶人：N 號白狼王自爆。天黑請閉眼。）自爆的或被帶走的是警長：等他選完警徽才唸天黑（見 day-7）。今天不放逐。警長競選中自爆跟 wolf-3 一樣先公布死訊（哪些情況自爆不算，見 day-10）。
  • 被帶走的獵人、狼王可以開槍，開完才唸天黑；被帶走的是狼美人 → 她魅惑的人殉情。

限制

  • 不是自爆出局就不能帶人（被刀、被放逐、被毒都沒有技能）。今天的放逐登記之後不能自爆（時機同 wolf-5）。

狼美人 狼人陣營

狼人陣營，晚上和狼隊友一起殺人。狼人殺完人後，再單獨睜眼魅惑一個人（不能連續兩晚魅惑同一人）；狼美人出局時（被放逐、被槍帶走、被白狼王帶走），魅惑的人跟著殉情出局，殉情的人不能發動技能。被騎士撞死、被女巫毒死不會殉情。狼隊不能刀狼美人，狼美人不能自爆。

技能

  • 晚上和狼隊一起殺人；狼人閉眼後單獨睜眼魅惑一個人狼美人請睜眼。請選擇今晚要魅惑的玩家。可以選任何活著的其他人（包括狼隊友；魅惑到狼王，殉情時一樣不能開槍），不能選自己，也可以不魅惑。
  • 魅惑一晚有效、每晚換新：只看前一晚魅惑了誰。前一晚選「今晚不魅惑」（或那一步被跳過），就沒有人會殉情，更早以前魅惑的人不會延續。
  • 殉情：狼美人被放逐、被槍帶走、被白狼王帶走 → 她魅惑的人跟著出局，主機唸M 號殉情出局。殉情的人不能發動技能（獵人、狼王不能開槍）。
  • 剩一狼美、一神、一民時狼美被放逐、魅惑的人還活著 → 殉情算狼刀、狼刀優先 → 狼人陣營獲勝（屠邊；屠城時剩下的人是好人，好人勝）。

限制

  • 不能連續兩晚魅惑同一位（畫面上昨晚魅惑的那格標「昨晚魅惑過」）。
  • 被騎士撞死、被女巫毒死 → 殉情被悶，魅惑的人沒事。
  • 狼隊不能刀狼美人；狼美人不能自爆。

隱狼 狼人陣營

狼人陣營。你知道狼隊友是誰，他們不知道你。晚上在手機上跟狼人一起投票殺人（不用睜眼，狼隊只看到「隱狼」選誰、看不到你的號碼）；預言家查你、守墓人看你都是好人。白天可以自爆。

技能

  • 單向認人：手機上看得到狼隊是誰；狼隊不知道他。
  • 夜裡在手機上跟狼隊一起投刀，不用睜眼；全體一致也要算他（掉線不算）。狼隊手機只看到「隱狼：選幾號」，看不到他是幾號；隱狼死了，狼隊照樣看到「隱狼：還沒選」（不會直接看出死掉的哪一個是隱狼）。但隱狼死了或掉線時就不等他：狼隊自己一致就能確定，所以狼隊可能從「沒等隱狼」推出他不在。
  • 預言家、守墓人看是好人：預言家查他、守墓人看他都是好人。石像鬼查他看到角色名稱「隱狼」。騎士決鬥照真實陣營＝狼人。
  • 狼隊（狼人、狼王、白狼王、狼美人）全部出局後，不用再跟狼隊一致，在同一步自己決定殺誰（有石像鬼的話彼此見面、一起決定）。板子上本來就沒有狼隊時，第一晚就這樣。
  • 白天跟大家一樣投票；可以自爆（唸「狼人自爆」）。

石像鬼 狼人陣營

狼人陣營，不跟狼隊友見面（互相不知道）。每晚查驗一個人的具體身分。狼隊（狼人、狼王、白狼王、狼美人）全部出局後，你才開始在晚上殺人。白天可以自爆。

技能

  • 查具體身分：預言家之後單獨睜眼石像鬼請睜眼。請問你今晚要查驗的玩家是？查一個活著的其他人，看到他的角色名稱（不只好壞）。
  • 狼隊（狼人、狼王、白狼王、狼美人）全部出局後（隱狼還活著也一樣），晚上在「狼人請睜眼」那步殺人（跟隱狼一起時彼此見面）；查驗照常。板子上本來就沒有狼隊時，第一晚就開始。
  • 白天可以自爆（唸「狼人自爆」）。

限制

  • 不跟狼隊見面：狼隊不知道他、他也不知道狼隊；狼隊還活著時不參與狼刀。預言家查是狼人。

神職（好人）

預言家 神職

每晚查驗一個人（不能查自己），知道他是好人還是狼人；隱狼查起來是好人。

  • 每晚查驗一個活著的其他人，自己手機顯示 👍 好人／👎 狼人；一晚只能查一人。
  • 隱狼查起來是好人；其他狼人陣營（含石像鬼）都是狼人。
  • 查驗結果只在自己手機；以前查過的紀錄隨時看得到。

女巫 神職

解藥可以救今晚被狼刀的人，毒藥可以毒死一個人（不能毒自己）。兩瓶各只能用一次，一晚只能用一瓶；能不能救自己看設定。

技能

  • 解藥女巫請睜眼。今晚死亡的玩家是——請問你要使用解藥嗎？手機顯示今晚被刀的號碼，可以救或不救。解藥用掉後就看不到誰被刀。狼人空刀時沒有人可以救。
  • 毒藥請問你要使用毒藥嗎？如果要，請選擇你要毒殺的號碼。毒一個活著的人，或不使用。被毒的人不能開槍，守衛也守不住。

限制

  • 兩瓶藥各只能用一次，一晚只能用一瓶（今晚用了解藥就不能再毒）。
  • 不能毒自己。自救看設定：都不能（預設）／只有第一晚能／每晚都能。
  • 救的人剛好也被守衛守 → 同守同救，那人反而死。

獵人 神職

被狼刀、被放逐、被槍帶走或被白狼王帶走時，可以開槍帶走一人；被女巫毒死、殉情不能開槍。夜裡會看到自己今晚能不能開槍。

技能

  • 開槍：被狼刀（包括同守同救而死）、被放逐、被狼王的槍帶走、被白狼王帶走出局 → 自己手機出現開槍，帶走一個活著的人或不開；主機喊N 號，請啟動角色技能。開了唸N 號發動技能，帶走了 M 號。不開槍時主機不唸、紀錄也不寫。不限時。這一死讓勝負直接成立（例如屠邊時他是最後一個神）就不用開槍了（只有狼王會先等他開槍，見 all-5）；如果只是湊成綁票或一狼一神一民，會先等他開槍再判（他帶走狼，就可能不成立）。
  • 帶槍手勢：夜裡獵人那步（守墓人之後、第一晚的上警之前）獵人請睜眼。獵人，你今晚的帶槍手勢是——手機顯示 👍 可以開槍／👎 今晚不能開槍（今晚被毒）。

限制

  • 被女巫毒死、殉情不能開槍。
  • 還沒開槍時大家要等（不能投票、放逐）；主機按天黑＝這一槍作廢。

守衛 神職

每晚守護一個人不被狼殺（可以守自己、可以空守；守不住女巫的毒）；不能連續兩晚守同一人。跟女巫救同一人，那人反而會死。

技能

  • 每晚守一個活著的人（可以守自己），或空守。守到狼刀的人 → 那人活。

限制

  • 不能連續兩晚守同一人（空守之後隔天守誰都可以）。
  • 守不住女巫的毒；跟女巫救同一人 → 同守同救，那人死。

守墓人 神職

從第二晚開始，每晚得知前一個白天被投票放逐出局的人是好人還是狼人（隱狼會顯示好人）。

  • 第二晚起在石像鬼之後睜眼守墓人請睜眼。昨天被放逐的玩家，他的陣營是——手機顯示前一個白天被投票放逐出局的人是 👍 好人／👎 狼人（隱狼顯示好人）。
  • 只看投票放逐：平票沒人出局、白癡翻牌免死、自爆、被槍或白狼王帶走、騎士撞死、殉情都不算 → 顯示「昨天沒有人被投票放逐出局」。白癡被放逐後選不翻牌出局，算放逐。

騎士 神職

白天隨時都可以翻牌和一個人決鬥（只能一次；有人在開槍或做選擇、或今天已經要天黑時要等）：他是狼人就出局、今天直接天黑；不是狼人，騎士自己出局。

技能

  • 白天隨時決鬥（在「看我的身分」裡）：警長競選中、投票中（這輪投票作廢）、放逐之後都可以。警長競選中決鬥＝先公布昨晚死訊（哪些情況決鬥不算、也沒用掉，見 day-10）。
  • 對方是狼人陣營（照真實陣營，隱狼、石像鬼也算） → 對方出局、今天直接天黑（還沒放逐的話就不放逐了），主機唸騎士 N 號決鬥 M 號：M 號是狼人，出局！天黑請閉眼。主機按「進入黑夜」。撞到狼王 → 狼王先開槍再唸天黑。
  • 對方是好人 → 騎士自己出局騎士 N 號決鬥 M 號：M 號是好人，騎士以死謝罪。白天繼續。

限制

  • 一局只能決鬥一次；只能選活著的其他人。等別人選擇（開槍、白癡翻牌、警長移交）的那一下、或今天已經要天黑時不行。夜裡沒有動作。

白癡 神職

第一次被投票放逐時可以自己選翻牌免死（之後不能再投票），或不翻直接出局；翻過牌再被放逐就直接出局。被狼刀、被毒照常出局。

  • 第一次被放逐：主機不唸，等他在自己手機選「翻牌（免於出局）」或「不翻牌，出局」；主機不能代按、不限時。翻牌唸N 號翻牌，是白癡，免於出局，但之後不能投票。不翻牌唸N 號被放逐出局。（算投票放逐，守墓人當晚看得到他）不管翻不翻，今天的放逐都算完成了（今天不能再投票、PK，狼人也不能自爆）。
  • 翻過牌之後沒有投票權（綁票也不算他的票）；再被放逐直接出局。
  • 被狼刀、被毒、被槍帶走等其他死法照常出局。夜裡沒有動作。

平民（好人）

平民 平民

沒有技能。靠推理和投票找出狼人。

  • 沒有技能，夜裡不睜眼；白天發言、投票。屠邊時平民全部出局，狼人陣營就獲勝。
